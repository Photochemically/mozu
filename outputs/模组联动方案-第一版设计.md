## 1. 玩家实际会玩到什么

玩家可以先用基础装备探索城市，带回金属、少量弹药和怪物材料。回家后，一部分资源直接补给，一部分经机械加工变成更多弹药或特色装备。工业发展提高出行的持续能力；城市之外的维度门探索，则提供适合装备部件与神秘加工的材料。Apotheosis 继续提供装备筛选、宝石和重铸方面的长期目标。

主循环：

```mermaid
flowchart LR
  A[城市与野外探索] --> B[金属、弹药、怪物材料]
  B --> C[Create 与沉浸工程加工]
  C --> D[TaCZ 补给与 Silent Gear 装备]
  D --> A
  D --> E[维度门与强敌挑战]
  E --> F[特色材料与装备养成资源]
  F --> D
```

各路线允许独立起步。工业可以提高效率，探索可以获得工业替代来源，战斗可以提供装备材料；只有少数特殊升级才要求指定挑战。

### L01：先做两种弹药的生产线

已核实的 TaCZ 默认配方：

| 弹药 ID | 原始消耗 | 产出 |
|---|---|---:|
| `tacz:9mm` | 铜锭 ×10、火药 ×2 | 50 |
| `tacz:556x45` | 铜锭 ×15、火药 ×3 | 45 |
| `tacz:762x39` | 铜锭 ×15、火药 ×3 | 35 |
| `tacz:12g` | 铜锭 ×15、火药 ×6、铁粒 ×18 | 18 |

这些来自 JAR 内默认枪包；外置枪包或实例脚本可能覆盖它们。

**第一轮建议：**只覆盖 9mm 和 5.56，保留原始枪械伤害与手工配方。工业线总成本以原始资源等价量为参照，先试验约 20% 的产出改善，即同等铜/火药投入目标为 60 发和 54 发。具体每道工序的批量要满足机器输入、输出及堆叠限制；这些数字目前是整条生产线的设计目标，尚非可安装配方。

可以增加少量弹壳/半成品，让压制和装配有可见作用。先使用现有铜材供应；黄铜与铅弹头方案放到第二轮比较，避免未经核算就让一种更便宜的路线全面替代原路线。

希望得到的体验是：偶尔用枪可以手工补充，持续远征值得建设弹药生产线。检验时既看总材料消耗，也看占地、机器、能量、加工速度和已有火药农场。

**技术要点：**`tacz:9mm` 是弹药内容 ID，不应未经验证就当作独立注册物品直接输出。必须构造带正确弹药标识的物品堆，并实际装填、开火验证。当前版本已有相关 KubeJS 构造接口。

### L03 / L04：让怪物材料带来装备选择

暗金属已有完整原生关系：9 片 `born_in_chaos_v1:pieceofdarkmetal` 可以组成一堆，再高炉炼成 1 个 `dark_metal_ingot`；单片也能高炉炼成 1 个暗金属粒，9 粒合成 1 锭。新增加工必须同时核对这些路径。

建议给 `born_in_chaos_v1:dark_metal_ingot` 添加 Silent Gear 材料定义，以 IE 钢作为中期比较基准。优先体现耐用或修理方面的差异，让攻击速度、附魔适性等留出取舍。第一轮不要直接添加百分比伤害叠加、吸血或无条件免伤。

`born_in_chaos_v1:monster_skin` 已参与原生装备配方，适合作为握柄/衬里候选。新增定义时按部件限制用途，避免一张皮自动成为高等级武器、护甲与飞行装备的通用材料。

暗金属原生护甲板需要暗金属锭和怪物皮，已有独立价值；新路线的成品应与原生装备比较，不能只比较 Silent Gear 内部材料。

### L05：城市奖励应有明确用途

建议城市的一般补给以基础金属、少量弹药为主，铁路场所偏向板材、钢和其他工业资源。高级零件只能占少量，基础生活物资仍要保留。

**关键发现：**Lost Cities 的 `chestloot.json` 会选用自己的城市/铁路掉落表，也会选用许多原版箱子表。因此，只修改 `lostcities:chests/lostcitychest` 不会覆盖全部城市箱子；直接改原版地牢表又会把影响扩展到城外。

正确的实施路线是先核对正在使用的城市预设，再调整城市自己的箱子分配与自定义表，并测试新生成的不同楼层、铁路和普通建筑。现有已开启箱子的内容不会因改表自动重建。城市还必须实际出现在所选世界生成配置中，装了模组不等于已经生成城市。

第一轮不直接大量投放顶级枪械或完成养成的装备。玩家应能从开箱获得补给和发展机会，同时保留制造的用途。

### L06 / L09：维度探索形成另一条材料路线

已确认 `dimdoors:dungeon_chest` 包含 `dimdoors:world_thread`；原生织造配方把 4 个世界纤维制成 1 个 `dimdoors:stable_fabric`。该材料还参与裂隙珍珠制作。

第一轮优先以世界纤维或稳定构造作为绑带、弓弦材料候选，采用 Silent Gear 已有特性和有限参数，不承诺自动继承维度门原装备的特殊能力。

第二轮可以做一个明确标注为本整合包新增的“星纤维”中间材料：由稳定构造与 `enigmaticlegacy:astral_dust` 加工，用于更有特色的部件。星尘继续从原玩法获取，不能用常见怪物粉尘无限兑换。部件只是获得我们定义的属性，不会自动具备任何 Enigmatic Legacy 装备技能。

Enigmatic Legacy 的部分配方使用 `crafting_shaped_cursed`。本次检查的对应配方实现对 `ITaintable` 原料调用 `isTainted` 检查。因此，不能把它们简单改成普通机械配方后宣称等价兼容；配方条件、物品启用条件及相关使用限制需要分别保留。

### L10：Apotheosis 保留自己的核心循环

其普通词缀装备已有分解路线，普通材料回收量在内置配方中是 1–4。重铸按稀有度有材料、印记和等级成本。第一轮保留这些关系。

工业联动先考虑少量辅助耗材，或对原本已经拆出的资源提供有限用途。不要直接用普通金属大量合成高稀有度材料，也不要把任意 Silent Gear 装备扔进粉碎机后无条件返还全部原料。附魔、词缀、宝石、部件数据与耐久都可能影响回收是否合理。

宝石及词缀战利品还涉及全局掉落修改器。实施探索奖励时要确认原来是否已注入，避免重复增加。第一轮不假定 TaCZ 枪械可以直接继承所有弓词缀、吸血或饰品增伤。

### L11 / L12：强敌奖励与区域难度后做

突变骷髅有专门的肢体掉落表，如 `mutantmonsters:entities/mutant_skeleton/limb`，而普通实体掉落表本身是空的。不能据此判断它不掉奖励，更不能直接用一张通用掉落表取代特殊死亡流程。拟议杆件可以使用 `mutantmonsters:mutant_skeleton_limb`，先核实回收方式、现有用途和获取频率。

In Control 已有城市与建筑判断，适合做区域差异；但区域条件、生成许可和主动新增生成是不同事情。实施时要分别核对自然生成、刷怪笼、召唤物与特殊事件，设置数量边界，并测试刷怪农场的影响。

先让奖励与补给循环成立，再用实际战斗数据决定哪些城市区域需要增加压力。第一轮不预设全世界统一加血或按天数强制升级。

## 4. 第一版范围与完成标准

第一版建议包含 L01–L07：两种工业弹药、现有金属路线说明、暗金属与怪物皮材料、一个维度纤维材料方案、城市奖励分配及联动指南。可以只新增少数半成品，避免大量同质材料。

| 阶段 | 玩家获得的进展 | 检查重点 |
|---|---|---|
| 早期 | 能用基础装备探索，拾取少量弹药和材料 | 不需要稀有战利品才能开始工业或正常生存 |
| 初步工业 | 自动化金属加工与两种弹药补给 | 相比手工有实际收益，机器之间输入输出兼容 |
| 中期战斗 | 工业金属与怪物材料形成不同装备选择 | 原生装备和近战仍有使用价值 |
| 维度探索 | 获取并使用特色纤维 | 不用虚构新增能力，也不绕过原生织造链 |
| 长期养成 | 保留宝石、重铸、稀有饰品及强敌追求 | 不能用普通工厂无限复制高阶资源 |

验收需要包括：

1. 在与目标实例一致的 Forge 环境加载，检查脚本、数据包、材料与配方报错；重启后仍正确。
2. 每条工业配方从原料完整跑到成品；两种弹药均可装填、开火，联机时客户端与服务端一致。
3. 检查压制、分解、粒锭块互换及新增加工路线，确认不存在资源正收益循环。
4. Silent Gear 各候选部件可以制作、修理、保存、重新读取；验证原生装备仍有用途。
5. 在新生成的城市建筑、铁路与维度门箱子验证奖励；检查全局战利品注入是否导致额外倍增。
6. 用同一组敌人比较基础装备、工业装备与养成装备，记录击杀时间、弹药消耗、承伤及修理成本；在实际异常处调整数值。
7. 对特殊死亡奖励、刷怪笼与召唤物做单独检查，不把普通野怪测试结果外推给所有实体。

以上是后续验收要求，本次尚未执行。
