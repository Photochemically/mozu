## 后续开发约定

1. 小改动检查涉及的文件；一批相关改动完成后统一检查依赖与数据引用，不对未改变的内容重复全量检测。
2. KubeJS 脚本和 JSON 数据通常没有独立编译步骤，采用语法、格式、字段与引用检查。只有新增 Java 兼容模块等需要构建的内容才编译。
3. 将需运行确认的事项登记在本文件，开发阶段不反复开游戏、建世界或执行重载。
4. 集中验收时优先处理枪弹匹配检查问题，再验证真实生产线、材料部件、箱子和完整游玩循环。

临时运行检查脚本不属于发布文件，停止本轮运行测试后移除。已建立的测试世界保留，便于最终验收复用。
