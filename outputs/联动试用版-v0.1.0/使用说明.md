# 远征与工坊：联动试用版 0.1.0

适用实例：`C:\Users\hp\AppData\Roaming\.minecraft-forge-3`。

适用版本：Minecraft 1.20.1、Forge 47.4.10，以及本次核查的 Create 6.0.8、TaCZ 1.1.8-hotfix2、Silent Gear 3.6.7 等模组组合。此包为首轮玩法试用，不代表战斗平衡已最终完成。

## 已加入的内容

| 内容 | 使用方法 |
|---|---|
| 工业 9mm | 工作盆中放 5 铜锭，用 Create 动力辊压机压制为手枪弹壳批次，再用机械手消耗 1 火药，产出 30 发 |
| 工业 5.56 | 工作盆中放 5 铜板，压制为步枪弹壳批次，再用机械手消耗 1 火药，产出 18 发 |
| 暗金属材料 | Born in Chaos 的暗金属锭可作 Silent Gear 主材和杆件，偏耐用；与钢相比有护甲、攻速、附魔适性等取舍 |
| 怪物皮材料 | 可制作 Silent Gear 握柄和衬里，保留原生装备用途 |
| 稳定构造材料 | Dimensional Doors 的稳定构造可作 Silent Gear 绑带和弓弦，仍通过原生织造链获得 |
| 城市补给 | 保留原箱子表，城市箱子有 60% 机会追加一份基础补给，铁路箱子为 75%；物品从加权池中选择，不是每种物品各有这个概率 |
| 中文指南 | 第一次进入世界自动获得；可用 1 本书＋1 铜锭无序合成补领 |
| 物品提示 | 弹壳批次与关键材料显示新增用途；两种批次复用原有铜材图标，以名称区分 |

两种工业弹药在相同铜和火药消耗下，比原手工配方多产 20%。还需投入机器、动力及加工时间。原手工配方、枪械伤害、怪物数值、诅咒机制、神化分解重铸及世界生成配置均未修改。

城市奖励仅作用于 Lost Cities 对应箱子分配规则。这个包不会强制把主世界变成城市；创建世界时需要选择相应预设，或使用已配置的城市维度。既有箱子是否受影响取决于奖励是否已生成，已打开的箱子不会自动补货。

## 安装与更新

本次已按文件清单安装到上述实例。完整关闭并重新启动游戏才能加载新增物品。文件只位于实例的 `kubejs` 内，不需要替换 JAR，也不需要修改外置枪包。

另存或重装时，将“安装内容”中的 `kubejs` 合并到对应游戏实例；不要用整个文件夹替换已有的 `kubejs`。若已有同名文件，先备份并核对来源。

`文件清单.json` 记录发布文件与指纹；`安装记录.json` 记录此次安装位置和原文件备份位置。检查结论见同目录 `验证结果.md`，静态检查不能代替游戏运行测试。

## 撤回本次安装

先关闭游戏，再运行同目录 `撤回本次安装.ps1`。它只处理安装记录中的文件：有原文件则恢复，没有原文件则删除新增文件。若发现某个文件在安装后又被修改，会停止并要求人工核对，避免覆盖后续工作。

如果在正式存档里已经制作并使用新增物品或材料，先备份存档再撤回。移除新增物品/材料定义可能使对应物品或装备部件失效；撤回文件并不是撤回存档内发生的一切。

## 推荐试用方式

先建临时创造世界检查物品、制作和机器生产，再在生存世界观察体验。重点比较补给成本、近战与枪械的使用比例，以及新材料是否有明确用途。

本次没有新增地区刷怪，也未处理全部模组的战斗效果叠加。Enigmatic Legacy 星纤维加工、突变肢骨材料和神化辅助耗材属于后续设计，不在这个安装包内。
