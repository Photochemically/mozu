# 七类验收入口：开发辅助模块

2026-11-04。仅用于可丢弃的独立测试存档。本模块提供管理员放置案例入口的命令，不是预先生成好的测试地图，也不代表任何实际建筑或传送已验收。桥接尚未安装，Minecraft 未启动。

## 开启范围

1. 后续集中验收时，使用单独的 Forge 验收实例与新测试世界；不要复制正式生存世界来启用主动创建功能。
2. 将本目录 `test-fixtures/expedition-development-world.json` 放在该存档根目录，与 `level.dat` 同级。服务器使用自己的世界目录，客户端资源包／全局配置目录不生效。仅将模板放在开发工程里不会开启任何游戏功能。
3. 执行者需要4级管理员权限。测试分支在命令权限和执行阶段都检查权限；每次执行还检查当前存档的标记文件。不提供游戏内开启标记的命令。单人验收世界需要启用作弊；专用服务器需配置相应权限。
4. 标记只能表明管理员明确选择了测试存档，不能自动证明存档没有重要数据。正式存档不得放入该文件。移除标记会禁止后续创建；已生成实例继续保留并沿用正常往返机制，不主动清理世界。

```json
{
  "schema": 1,
  "purpose": "l13_disposable_acceptance",
  "allow_test_entrances": true
}
```

不会启用或替换正式地牢目录、自然入口开关、自然布局记录、不稳定等级权重。测试内容在入口创建时明确固定，以便复现；正常自然门依旧在首次未进入边狱的有效进入时选择内容。

## 命令

```text
/expedition test list
/expedition test entrance <案例> <x y z> [种子]
```

坐标是门下半部分所在的空气方块，允许相对坐标。只接受主世界已加载、安全位置：周围3×3有稳定地面，上方3层为空，地形在边界和高度内，当前区块没有结构引用。不会自动清理建筑、铺平台或强制加载区块。所有案例入口朝北；与已有实例入口水平距离至少8格，包括关闭／失败记录。快速验收世界最多32个实例，之后应另建测试世界，不能据此宣称全候选批量验收完成。

默认内容种子为 `20261104`。同案例、同坐标、同种子重复执行仅报告既有UUID与状态；不重建门、不刷新地牢。换种子也不能覆盖同一入口位置。输出的UUID可直接用于：

```text
/expedition audit snapshot <实例UUID>
```

门创建后实例仍为NEW，无目的地、无参与者、无口袋分配。首次进入使用现有生成队列、身份校验、出口改写、保存和传送服务。普通门与不稳定门的原边狱概率照常生效；本模块尚未提供强制结果。因此固定建筑种子不代表固定玩家传送结果。金门仍不抽取边狱。

城堡此前通用地表96比原低层地面高31格，本轮按原模板改为65：固定起点54减原生groundLevelDelta=1，模板底部为53，低层脚部高度为局部12。静态方块／空气分析找到从入口一侧到低层内部的保守连续路线；不改原模板、不裁剪250格高度。这不是实际碰撞、随机部件、机关或完整上下层路线验收。证据见audit/keep-kayra-ground-evidence.json，详见[本批建筑完整性记录](WDA_COMPLETENESS_STAGE1.md)。已选内容仍保持旧快照，既有测试实例不会被自动调整；应使用新测试世界或新位置创建修正后的案例。

## 建议验收顺序

准备阶段先检查维度、列出案例，在安全空地放置小房间与营地入口。用状态快照确认NEW、目的地为空，再亲自进入；观察生成完成、出口返回和再次进入。随后测原生多出口、风车及金门／竹门双人状态。最后单独运行超高城堡，记录规划及首次生成卡顿。

放置命令不启动建筑生成，管理员可以先放多扇门再逐个进入。建筑种子只固定WDA规划输入；不宣称原生DD房间内部随机过程或所有战利品均由该种子控制。

配合原有snapshot命令，在双人进出、断线、生活空间暂离与正常重启前后成组导出。地图内宝箱、标记方块、怪物状态仍须实际核对；快照不是这些内容的验收证明。

原生空间保护新增验收：在不同位置创建两扇相同原生案例门并分别进入，确认建筑、返回锚点和裂隙互不串联；检查小房间原外壳的边缘区块完整生成，随后正常重启复查。保留一组铁门／石英门正常往返检查，以验证局部注入没有改变自建空间。不要通过删除存档文件来模拟崩溃；异常中断恢复应在专门的可丢弃副本中另行安排。实现范围见[原生房间空间记录](NATIVE_ROOM_RESERVATIONS.md)。

尚缺：一键预置地图与坐标表、可重复的边狱强制输入、自然入口统计区域、完整奖励／首领诊断、总报告收集器。测试门不经过自然密度／选型／候选加权过程，不可作为这些功能通过的证据。

原生房间内部路线及天空效果的新增实现见[路线适配](NATIVE_ROOM_ROUTES.md)，两处已授权替代WDA部件及接合／战斗验收项见[缺失模板说明](WDA_TEMPLATE_GAPS.md)。当前七类案例没有覆盖全部新适配房间，需在最终测试地图批次补齐对应案例；不能把125份原定义中98份通过策略检查当成98个房间实机通过。
