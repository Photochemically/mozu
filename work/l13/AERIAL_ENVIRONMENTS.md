# 空中建筑：保留原平台的入口模式

2026-11-05。新增可选组合 `surface: "void"` 与 `entry_mode: "start_deck"`。使用原建筑、原平台和桥梁；不在下面填满统一地基，也不新增平台覆盖机关。尚未启用正式候选、安装桥接或进行实机验收。

这里只修改背景与进入方式。原生成器先得到完整组件图，再整体平移到预留口袋；原定义的绝对高度不是平移后的最终世界坐标。全部组件、相互高度、处理器与原资源保留。现有16格预留余量及完整高度检查不变，不裁剪超高建筑。

## 代码行为

- void 与 start_deck 必须成对出现，不能带水深或登船栈道。旧候选默认仍为 perimeter，地下 start_room 仍要求岩层。模式随首次选择保存。
- 空中模式只接受已检查的原版jigsaw、无地表投影及全体刚性放置组件。不会把依赖地形的组件忽略掉；不满足条件时停止生成。机械巢穴须通过专用原桥连接规划；无可识别原桥时在分配前报错，实际放置后无安全桥面时隔离实例。
- 不写入地形方块，规划与放置的背景高度图均视为空。预留完整建筑范围；临时记录点保证在范围内，只有实际入口与所有出口安装并完成保存屏障后才开放。
- 完成全部原建筑放置后，普通空中模式从原起始组件低处逐层找平台；机械巢穴只沿闸门外实际原桥的同高路线选址。落点需要3×3支撑、上方3层可通行、门本身两格为空气。原步行连通区域至少24格、横纵跨度各至少5格，并连接组件边缘；不把模板几何中心当作实际甲板中心。
- 原铁轨／地毯可以走过但不能被门替换；地毯只允许位于脚下层，不能误当作头部无碰撞空间。干燥倒置楼梯的完整上表面可以支撑；普通楼梯、含水方块、危险方块和设备仍不当作安全支撑。实际放置前再检查真实支撑面。
- 其他出口继续按原房间分散选择，总数需达到候选要求的1～4扇。找不到全部安全位置时保留并隔离实例，不减少数量、不重抽建筑、不重生成。再次进入使用保存的起点，返回主世界、边狱及生活空间规则不变。

每次选址最多256个工作单位／约4毫秒软预算；单组件扫描上限200万格，连通检查上限65536个节点。超出上限需要专门适配，不宣称穷尽所有路线。原结构放置仍有不可拆分操作，首次生成负载需要实测。

void 保留旧环境字段格式，first_free_y、padding、rim、foundation_depth 在此模式下不产生地基；完整建筑高度与预留范围仍有效。岛屿体积报告为0，区块范围仍覆盖完整建筑。现有七类快捷案例尚未包含本模式。

## 证据与未完成事项

`audit/aerial-entry-audit.json` 记录48个原始起始组件旋转案例：44例找到安全平台，机械巢穴4个根模板负例仍保留；它们由另行测试的专用连接桥流程处理。原资源证据在 `audit/special-environment-source-evidence.json`；机械巢穴闸门局部方块证据另存。其处理器可能将装饰方块变为TNT，静态审查保守纳入所有可能输出，未按普通地板放行。

这不是48座完整地牢验收，也不是正式等级／权重配置。原随机附加组件、跨组件路线、门实际碰撞、粒子、战斗、掉落、双人进出、首次生成负载及重启保存仍待集中验收。机械巢穴完整拼装/实机路线、小飞艇完整生成与攀爬、两类地表矿井及其他特殊结构仍保留在待办中。

上一批空中模块构建161项Java测试通过，其中新增14项。机械巢穴检查点完整构建168项通过；机械巢穴桥侧入口已有代码；96个原桥连接组合中84例找到安全平台、12例明确拒绝，保留原闸门和机关，完整随机生成与实机验收仍未完成。两组样例范围不同，不能表述为48座建筑全部通过。
