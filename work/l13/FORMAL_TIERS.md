# 正式五级池与 NPC 难度规则：设计提案

2026-11-28 · 设计草案，待用户定案，当前未实施。依据 2026-11-28 玩法决定：所有可交付地图可在五级探索门中抽到，各级保留非零候选权重；高难度提高大型地图的相对权重，并调整同图内部遭遇、陷阱和奖励。本文件只提提案，不锁定任何正式参数。

## 规模分级提案（依据既有审计证据，待定）

39 座建筑按主体尺寸、模板数与拼装复杂度分为四档；规模不与战斗等级硬绑定，只影响同等级内的相对权重与遭遇密度。

| 档 | 建筑（提案） | 依据摘要 |
|---|---|---|
| S 小型 | merchant_campsite、illager_campsite、fishing_hut、wishing_well、草原/蘑菇小屋、giant_mushroom、illager_windmill、lighthouse、jungle_tree_house、small_blimp | 单/双主体、低模板数；oak_camp 已实机 READY |

| X 巨构 | shiraz_palace（144×96×144）、thornborn_towers（34 资源、绝对根 129） | 首件负载最高，保留完整尺寸 |

## 五级权重提案（待定，未实施）

- 每级对全部可交付候选保持**非零权重**（已在目录模型约束：每级必须有候选）。
- 高等级提高大型地图相对权重。示例方向（数值仅为示意，正式值待用户确认）：I 级 S/M/L/X ≈ 55/30/12/3，III 级 ≈ 35/35/22/8，V 级 ≈ 20/35/30/15。
- 同图内部遭遇、陷阱与奖励按等级调整：等级越高，同一地图使用更多/更强遭遇件、更少友好件，奖励表不变但首领/精英附加池随等级扩展。
- 不稳定门先抽等级再抽内容，等级权重继续沿用 settings.json 的 `unstable_tier_weights`（五级非负、合计大于 0），本批不提供内置默认值。

## NPC 与遭遇池规则（提案，待定）

- **友好/中立 NPC 保留仅在 I 级樱花木门**：merchant_campsite、greenwood_pub、mushroom_village、monastery 的村民/流浪商人/铁傀儡/海龟等原 NPC 仅在 I 级保留；II 级及以上默认改用仅含敌对怪物的遭遇池（具体名册与例外待定）。敌对建筑（illager_campsite、bandit_village、illager_fort 等）不受此条限制。
- 无友好 NPC 的建筑（hind、coliseum 等）保持原遭遇，不擅自增删。
- 机关保留：各等级均保留原建筑关键机关、刷怪设施与探索路线，已生成实例不做改动。

## 生成来源区分（设计原则）

- **首次生成实体**：原模板自带的实体放置（如海龟、村民、骷髅附件）——按上节 NPC 规则在 I 级保留、其他等级由遭遇池覆盖。
- **刷怪笼**：原模板刷怪笼数据保持原样，不随等级换池；刷怪笼是既有实例的一部分，重进不刷新。
- **后续补刷**：实例维度的自然补刷与神化/In Control 强化叠加按 L12/L13 分区规则另行处理（B3 批次），不在本文件定案。
- 奖励：原 WDA 战利品保留；III+ 与金门成长材料、一次性首领奖励仍属 B4 批次。

## 数据挂钩提案（未实施）

- 候选格式 v1 已支持每项 `tiers` + `weight`；若需"同图不同级不同遭遇池"，候选 JSON 增加可选 `encounters`（按等级覆盖遭遇池名册），默认空 = 保留原遭遇。
- 正式实现前必须先在隔离实例验证：选择确定性不受新字段影响、旧快照仍可解码、资源重载不重置已选实例。
- 开启正式目录不代表自然入口、战斗、奖励与保护系统完成；不单独作为发布开关。

## 待用户定案

1. 规模分档与五级权重具体数值；不稳定门等级权重。
2. 友好/中立 NPC 保留于 I 级的建筑名单与例外；II+ 敌对遭遇池的具体名册。
3. 同图按等级调整遭遇/陷阱/奖励的方式（换池、加精英件或改密度）。
4. 候选格式是否加 `encounters` 字段，以及实现批次（B3）。
