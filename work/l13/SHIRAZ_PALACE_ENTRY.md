# 繁花之宫：完整高台与北侧花园接入

更新：2026-11-20。锁定 WDA 2.1.58，目标 `dungeons_arise:shiraz_palace`。静态开发阶段，未安装、未启动 Minecraft。

## 完整建筑与高度

原目录 42 份模板，其中 27 块 48×32×48 主体构成三层完整宫殿，总外壳 144×96×144。原生成池实际使用十四种刷怪附件；`husk_elite_0` 虽在 JAR 中，但未列入原池，本批不擅自启用。实际可达模板为 41 份，不能将 42 份文件都称为已生成内容。

原唯一起始件 `part_13` 位于中央中层，WORLD_SURFACE_WG 偏移 +16，经 groundLevelDelta=1，根原点为名义地面加 15。基座比根低 32 格，原花园高台在基座加 32。施工岛面首个空层取基座加 33，即名义地面加 16；只调整背景地形，完整建筑内部坐标关系不变。原结构未指定 terrain_adaptation，缺省 NONE，不额外添加其他建筑的 12 格扩展。

当前支持 grass/rock 的 perimeter，boarding 关闭。原底层模板主要为高台砂岩基座，不使用瘟疫疯人院的厚岩层入口；所有主体、选中的原附件和原接口必须齐全、相连。缺件、错位、重复、错误朝向或原内容重叠会拒绝开放，不合成替代组件。

## 接入原北侧花园

原外边界留空，不能靠提高地表就假定可步行。桥在原空位上增加九块脚手架：外侧与原高台各一个支撑端，中间七格跨度。先放两端，再从两侧向中间施工，最大支撑距离四格；放置前逐格检查实际支撑和空气，拒绝覆盖原内容。

保留北侧原两格平滑砂岩台阶，分别是 east/outer_right、south/inner_left，均为 bottom 且 waterlogged=true。玩家经桥进入原台阶及第一格花园落脚，不清空水、不改台阶或植物。检查桥上与下台阶处的头部净空，全部指定 1～4 个岛缘出口必须连接桥外侧接近点。此证据只到原北侧花园；并未声称所有内部房间和上层已无障碍贯通。

## 原怪物、战利品与流体

完整主体有 66 木桶、62 宝箱、1873 水方块和 224 熔岩方块，原接口选中 61 个刷怪附件。按实际原池保留花园、塔楼、图书馆、精英、幻象和蜘蛛等原遭遇及其装备/效果/乘客配置。本批保留原强度，不是正式双人平衡或 Born in Chaos/Mutant Monsters/神化联动的完成状态。

施工后分批核对战利品表或固定容器物品、SpawnData/SpawnPotentials、刷怪间隔/数量/范围和原水/熔岩等级。宝箱随机种子和刷怪倒计时仍由原版处理，不误作模板常量。桥开工前完成原内容核对。

本建筑的水和熔岩 tick 在施工期间按已有机制暂存，原内容和入口检查通过后释放；含水台阶保持原状态。熔岩释放后的流动、点火、花园水流、脚手架实际行为及性能仍需游戏内验收。存档 schema 5、已生成空间永久保存、宝箱不刷新及返回规则不变。

## 验证与待验收

六项新增 Java 测试，24 组完整原件样例覆盖四旋转、两种干地、三种遭遇循环，各查 1～4 个出口、2286 个内容点和九格支撑桥。2026-11-19 最终完整 build 成功（2m46s），71 组共 325 项测试、0 失败/错误。首轮两项负例假设不符原接口/水位，修正后通过；原连接方块最终材质也纳入样例模拟。未执行原生随机生成器。

原件样例使用紧凑调色板与坐标数组，避免为近两百万格主体保留逐格对象；通过原连接接口拼装，非复刻原生随机生成器。最终测试结果见 `audit/build-summary.json`，原件证据见 `audit/shiraz-entry-audit.json`。原始日志仅本地保留。
